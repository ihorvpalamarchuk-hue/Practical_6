# Лавка зілля

Каталог еліксирів на чистому HTML, CSS і JS: чотири стани екрана, дизайн-система на трирівневих токенах, світла й темна тема.

## Структура

| Файл | Що всередині |
|---|---|
| `index.html` | розмітка: полиця зілля та UI-Kit |
| `tokens.css` | токени в шарах `@layer primitive`, `semantic`, `component` |
| `style.css` | стилі компонентів, лише через семантичні та компонентні токени |
| `app.js` | стани екрана, фільтр, додавання й видалення, тема |

## Стани екрана

| Стан | Коли з’являється |
|---|---|
| `loading` | при відкритті сторінки, «Оновити», «Повторити спробу» (1.8 с скелетону) |
| `content` | після завантаження, якщо на полиці є зілля |
| `empty` | випито все зілля або пошук нічого не знайшов; «Повернути запаси» відновлює список |
| `error` | кнопка «Помилка» на панелі станів |

Перемикає їх `renderState(stateName)` через клас `.is-hidden`.

## Дизайн-система

- **Primitive** — сирі кольори, відступи, розміри шрифту.
- **Semantic** — ролі: `--bg-surface`, `--text-main`, `--color-primary`, `--color-danger`.
- **Component** — `--btn-primary-bg`, `--input-border-error`, `--card-shadow`.

Темна тема (`[data-theme="dark"]`) перевизначає лише семантичні токени, тому класи компонентів не змінюються.

Розділ **UI-Kit** показує кнопки Primary / Secondary / Danger у станах default, hover, focus, disabled, поля в станах default, focus, disabled, error, а також картку.
